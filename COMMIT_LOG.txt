   - แก้ไข Path Resolution Bug บนระบบ Windows ใน `src/lib/audioTimeline.ts` และ `scripts/render.mjs`:
     เดิมทีคำสั่ง `path.isAbsolute('/uploads/...')` บน Windows จะประเมินผลเป็น `true` ส่งผลให้ระบบอ้างอิงไปยัง `C:\uploads\...` (ซึ่งไม่มีอยู่จริง) แทนที่จะเป็นโฟลเดอร์ `public/uploads` ในโปรเจกต์ ทำให้ `ffprobe` ล้มเหลวและวัดความยาวเสียงพากย์ได้ 0 วินาทีเสมอ
     ได้ปรับปรุงฟังก์ชัน `resolveAudioFilePath` และ `resolveAudioPath` ให้ตรวจสอบ drive letter (`^[a-zA-Z]:[/\\]`) และ `fsSync.existsSync` อย่างแม่นยำ รวมถึงตัด query parameter ออก ทำให้ `ffprobe` เข้าถึงไฟล์เสียงจริงได้ถูกต้อง 100%

   - ก่อนสั่งรัน worker เรนเดอร์ ระบบจะตรวจสอบความยาวเสียงจริงด้วย `ffprobe` และจัดสรรเวลาฉาก Hook, Scenes, CTA และคำนวณ `actualDurationFrames` ใหม่โดยอัตโนมัติ เพื่อป้องกันข้อมูลคลาดเคลื่อนตั้งแต่ระดับ API
